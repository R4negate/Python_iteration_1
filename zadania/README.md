# Zadania - Python iteration 1

Zadania wykonuj po kolei. Kazdy plik odpowiada jednej lekcji z `teoria/`.

Zalecany sposob pracy:

1. Utworz plik `.py` do zadania.
2. Napisz kod.
3. Uruchom plik.
4. Popraw bledy.
5. Dopiero wtedy przejdz dalej.

Nie chodzi o szybkie przepisanie kodu. Chodzi o zrozumienie, co robi kazda linia.
