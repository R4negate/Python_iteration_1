# Teoria - Python iteration 1

Czytaj pliki po kolei. Kazda lekcja konczy sie pytaniami kontrolnymi i malym cwiczeniem.

Najwazniejsze skojarzenia dla osob po SQL-u:

- `if` w Pythonie jest podobne do `CASE WHEN`,
- lista to wiele wartosci,
- slownik to rekord albo JSON,
- petla `for` przechodzi po elementach,
- funkcja to nazwany kawalek logiki,
- blad w Pythonie trzeba umiec czytac, nie tylko sie go bac.

- [04. Kolekcje](04_listy_slowniki_tuple_set.md): operacje, kopiowanie i referencje, sortowanie, rozpakowanie, zip.
- [05. Warunki i petle](05_if_petle_i_logika.md): for/while, zagniezdzenia, zakres z krokiem, sum/min/max oraz any/all.
- [06. Funkcje](06_funkcje_importy_main.md): wywolania, mutowalne wartosci domyslne, skutki uboczne i sortowanie przez key.
