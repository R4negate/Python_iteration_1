# Python iteration 1 - podstawy Pythona

Ten projekt zawiera materialy do pierwszej iteracji nauki Pythona dla osob, ktore przeszly juz podstawy SQL.

## Cel iteracji

Po tej iteracji powinienes umiec:

- uruchomic plik `.py` w PyCharmie,
- uruchomic prosty skrypt z terminala,
- uzywac zmiennych i podstawowych typow danych,
- pracowac z listami i slownikami,
- pisac warunki, petle i funkcje,
- czytac podstawowe bledy Pythona,
- napisac maly skrypt, ktory przetwarza liste zamowien.

## Struktura

- `teoria/` - materialy do czytania i omawiania.
- `zadania/` - zadania dla kursanta.
- `data/` - male dane treningowe.
- `examples/` - przykladowe pliki `.py` do uruchamiania.

1. `teoria/01_typy_danych.md` - typy podstawowe i zlozone.

3. `teoria/03_stringi_i_f_stringi.md` - stringi, czyszczenie tekstu i f-stringi.
